Privacy Policy

Last updated: 13 November 2026

Clipper Analytics is a private tool used by its owner to view statistics for the owner's own YouTube channels.

What it accesses

When the owner signs in with Google, the app requests read-only access to the owner's YouTube channel data and YouTube Analytics (for example views, subscribers, watch time, click-through rate and audience retention).

How the data is used and stored

The data is used only to show the owner their own channel performance. It is stored only on the owner's own computer. It is not sold, shared with, or disclosed to any third party, and it is not used for advertising.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Questions can be raised through the Issues page of this site's GitHub repository.
